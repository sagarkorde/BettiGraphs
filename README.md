# BettiGraphs

Persistent-homology-based structural profiling of Bitcoin transaction networks for anomaly
detection and wallet relationship analysis.

This repository holds the code for a pre-registered evaluation of persistent homology on the
Elliptic and Elliptic++ Bitcoin graphs: data acquisition, graph construction, persistent
homology, feature extraction, baselines and statistical testing, plus the pre-registered
protocol. The article itself is not distributed here.

The frozen hypotheses and evaluation protocol are in
[`docs/PREREGISTRATION.md`](docs/PREREGISTRATION.md); the revision experiments are described in
[`docs/REVISION_RUNBOOK.md`](docs/REVISION_RUNBOOK.md).

---

## What this project asks

Conventional Bitcoin forensics summarises a transaction graph with degree, centrality, motif and
clustering statistics. Each of those is a single-scale quantity. Persistent homology instead
summarises how structure appears and disappears *across a range of thresholds*, producing a
multiscale profile rather than a number.

The research question is whether that profile carries forensic information the conventional
statistics do not:

| RQ | Question |
|---|---|
| RQ1 | Do Betti-number profiles distinguish illicit from licit transaction structures? |
| RQ2 | Do persistent-homology representations improve anomaly detection over conventional graph features? |
| RQ3 | Does topological similarity between wallet ego-subgraphs measure behavioural relatedness? |
| RQ4 | Do temporal Betti signatures capture change that static features miss? |
| RQ5 | Does combining topological with conventional and learned features help? |

A note on what RQ3 does **not** claim: topological similarity between two wallets is a statement
about structural and behavioural resemblance. It is not evidence of common ownership, and this
project makes no attribution claim.

## Reproducing

Requires Python 3.10 and Git LFS. On Windows:

```powershell
py -3.10 -m venv --system-site-packages .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe data\download_scripts\get_elliptic.py
.\.venv\Scripts\python.exe data\download_scripts\get_elliptic_plus_plus.py
.\.venv\Scripts\python.exe -m pytest tests -q
```

Exact interpreter, package versions and hardware are recorded in
[`docs/ENVIRONMENT.md`](docs/ENVIRONMENT.md).

## Data

Neither dataset is redistributed here. The Elliptic release permits research use but does not
grant redistribution, and the Elliptic++ repository carries no licence file at all. The download
scripts fetch from the official sources and record source URL, byte size and SHA-256 for every
file in `data/raw/MANIFEST.json`; downstream code refuses to read an unmanifested file. See
[`data/README.md`](data/README.md).

## Layout

```
data/download_scripts/  fetch + checksum the datasets (raw data is git-ignored)
src/preprocessing/      validation and cleaning
src/graph_construction/ transaction, address and bipartite graph views; ego-subgraph extraction
src/topology/           filtrations, simplicial complexes, persistent homology
src/features/           Betti curves, persistence statistics/images/landscapes; classical graph features
src/models/             classical and graph-neural baselines
src/similarity/         topological wallet distances and retrieval
src/evaluation/         metrics, temporal splits, statistical tests
experiments/            one runnable experiment per subdirectory
scripts/                pipeline runners, analysis and figure scripts
tests/                  unit tests, including known-answer topology tests and leakage guards
docs/                   pre-registration, amendments, environment, revision runbook
```

## Reproducibility commitments

- `docs/PREREGISTRATION_FROZEN.md` is the pre-registration exactly as it was frozen on
  27 September 2026. Its SHA-256 matches the value in `docs/PREREGISTRATION_HASH.txt`
  (`45f643a7…1e43`); check with `sha256sum docs/PREREGISTRATION_FROZEN.md`. The freezing
  commit named there belongs to the private working history, which is not published because it
  also contains the article. `docs/PREREGISTRATION.md` is the current file with its amendments.

- Every hypothesis and metric was frozen, committed and hashed before any model was fitted.
- Every reported number is generated by a script that writes to `results/` (created on the
  first run). No value is typed in by hand.
- Scalers and persistence-image ranges are fitted on the training split only; no persistence
  diagram is computed on a graph mixing train-time and test-time edges. `tests/` enforces this.
- Primary metric is PR-AUC on the illicit class, under a temporal split, across 10 seeds with
  paired significance testing and Holm correction.
